# macagraf.github.io

Sitio publicado con GitHub Pages.

## Contenido

- `index.html` — Manual de marca y arquitectura web de MaCa (documento de una sola página, HTML y CSS sin dependencias de build).

## Origen

El documento se generó a partir de la revisión de los archivos locales de la artista: logotipo, mural, pirograbado, series de tatuaje, patrones de la cápsula textil y el cuaderno de poesía.

## Pendiente

Cuando se construya la home de obra, este repositorio pasa a ser el sitio completo: `index.html` será la portada y el manual se moverá a `/manual/`.
